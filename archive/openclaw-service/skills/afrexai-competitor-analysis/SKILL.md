# AfrexAI Competitor Analysis Skill

## Purpose
Systematically analyze a competitor's digital presence, pricing, features, and positioning to produce actionable intelligence for Hotels Vendors strategy.

## When to Use
- New competitor enters market
- Competitor launches new feature
- Quarterly competitive review
- Pricing strategy review
- Before investor presentation

## Target Competitors (Egypt)
- Suplyd (direct — HORECA procurement)
- MaxAB (indirect — FMCG B2B)
- OneOrder (indirect — restaurant supply)
- Farz Awal (indirect — restaurant supply)
- Travexs (indirect — hospitality B2B)

## Analysis Framework

### 1. Digital Presence Audit
```
Website:
- Domain authority (check backlinks)
- Page speed (Google PageSpeed)
- Mobile responsiveness
- SEO keywords ranking
- Blog/content frequency

Social Media:
- Facebook: followers, engagement rate, post frequency
- LinkedIn: company page, employee count, posts
- Instagram: followers, content type
- X/Twitter: presence, activity

Ads:
- Facebook Ad Library: active ads, targeting, creatives
- Google Ads: estimated spend, keywords
```

### 2. Product & Feature Analysis
```
Visit website and catalog:
- Product categories offered
- Number of SKUs (estimate)
- Pricing transparency (public vs quote)
- Minimum order quantities
- Delivery time promises
- Payment terms offered
- Return policy
- Quality guarantees

Features:
- Mobile app available?
- AI/ML features?
- Inventory management?
- Multi-property support?
- ETA integration?
- Credit/factoring?
- Logistics tracking?
```

### 3. Pricing Intelligence
```
Extract prices for benchmark products:
- Cooking oil (1L)
- Tomato paste (can)
- Cleaning chemicals (5L)
- Bed linens (set)
- Guest amenities (kit)

Calculate:
- Average markup vs retail
- Volume discount tiers
- Subscription pricing
- Delivery fees
- Compare with Hotels Vendors supplier prices
```

### 4. Customer Signals
```
Reviews & Testimonials:
- Google Reviews
- Facebook Reviews
- App Store reviews
- Trustpilot / similar

Sentiment Analysis:
- Positive themes
- Complaint themes
- Feature requests
- Churn signals
```

### 5. Financial & Funding
```
Public sources:
- Crunchbase / Magnitt funding
- LinkedIn employee growth
- Job postings (expansion signals)
- Press releases

Estimate:
- Team size
- Burn rate (from funding + runway)
- Revenue (if disclosed)
- Valuation (if disclosed)
```

## Hotels Vendors Response Playbook

### If Competitor Has Lower Prices
```
1. Check if it's a loss-leader or sustainable
2. Emphasize: quality guarantee, ETA compliance, logistics
3. Offer price-match for first order
4. Highlight total cost of procurement (not just unit price)
```

### If Competitor Has More Features
```
1. Identify which features hotels actually use
2. Fast-follow on must-haves
3. Differentiate on: AI assistant, coastal logistics, factoring
```

### If Competitor Raises Funding
```
1. Accelerate customer acquisition
2. Lock in exclusive supplier agreements
3. Launch defensive pricing for key accounts
```
