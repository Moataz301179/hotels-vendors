# AfrexAI Daily Briefing Skill

## Purpose
Generate a daily intelligence briefing for Hotels Vendors leadership by aggregating platform metrics, market signals, competitor activity, and operational alerts.

## When to Use
- Morning executive briefing (auto-generated)
- Weekly board update
- Pre-investor meeting snapshot
- Crisis response situation assessment

## Data Sources
- Platform database (orders, GMV, users, credit)
- Cashflow Compass (market direction, pricing, risk)
- Competitor monitoring
- Social media / news mentions
- ETA compliance status
- Delivery / logistics performance

## Briefing Structure

### Section 1: Platform Pulse (30-Second Read)
```
Yesterday:
- Orders: {count} | GMV: EGP {amount}
- New hotels: {count} | New suppliers: {count}
- Active credit lines: {count} | Utilization: {percent}%
- ETA invoices submitted: {count}
- Delivery on-time rate: {percent}%

vs. Last Week:
- Orders: {trend} | GMV: {trend}
- Sign-ups: {trend}
```

### Section 2: Market Compass
```
Direction: INFLATIONARY / STABLE / RECESSIONARY
Confidence: {percent}%

Key Signals:
- Supplier price momentum: {direction} {percent}%
- Hotel payment delays: {avg} days (trend: {improving/worsening})
- CBE rates: deposit {percent}% / lending {percent}%
- FX: EGP {rate} per USD

Alerts:
- {severity}: {category} — {message}
- {severity}: {category} — {message}
```

### Section 3: Competitor Watch
```
Suplyd:
- Last activity: {date}
- New feature: {description}
- Pricing change: {description}
- Funding: {status}

MaxAB:
- Last activity: {date}
- Expansion: {description}

Other:
- {Competitor}: {activity}
```

### Section 4: Operational Alerts
```
CRITICAL:
- {issue} — requires immediate action

WARNING:
- {issue} — monitor closely

INFO:
- {milestone achieved}
- {opportunity spotted}
```

### Section 5: Today's Priorities
```
Auto-generated from:
- Overdue approvals
- Pending credit applications
- Delivery issues
- Supplier audit deadlines
- Customer follow-ups

Example:
1. Approve 3 pending orders from Hotel X (value: EGP 150K)
2. Review credit application: Hotel Y (score: 650)
3. Follow up: Supplier Z (delayed delivery, 2 days overdue)
4. Call: Hotel A (churn risk, no orders in 30 days)
```

## Auto-Generation Schedule
```
- 08:00 AM: Generate daily briefing
- 12:00 PM: Midday alert check
- 06:00 PM: End-of-day summary
- Friday: Weekly deep-dive report
- Monthly: Board-ready executive summary
```

## Format Options
```
- Slack / Teams message (bullet points)
- Email (formatted HTML)
- PDF report (for board)
- Voice briefing (TTS for driving)
```

```
- Monthly GMV target vs actual
- Hotel acquisition target vs actual
- Supplier acquisition target vs actual
- Credit portfolio quality (default rate)
- ETA compliance rate
- Coastal logistics utilization
- AI assistant usage (messages/day)
```
