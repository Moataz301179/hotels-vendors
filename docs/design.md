# Project Design Contract & Token Enforcement

## 1. Color System & Contrast Mandates

- **Palette Lock:** Use ONLY designated HEX tokens. No unauthorized tints, shades, or bleeding background hues.
- **Accessibility:** Minimum WCAG AA 4.5:1 contrast required on all text layers. If a background luminance matches text color, inject a solid container card behind it automatically.

## 2. Layout & Hero Structure

- **Grid:** Strict 12-column alignment with mandatory 32px-48px negative space gutters.
- **Hierarchy:** Zero floating or arbitrarily centered text blocks. Left-aligned baseline standard.

## 3. Component Rendering Rules

- **Cards:** No flat rectangles. Implement glassmorphism or soft surface containers with 24px internal padding and subtle 1px borders.
- **Icons:** No generic 2D line icons. Use 3D matte-clay rendered assets styled with brand accent consistency.
