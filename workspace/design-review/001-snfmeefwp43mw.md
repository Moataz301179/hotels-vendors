- **NO glassmorphism** — solid dark cards

## Assessment for INVO Adaptation

### What Works for INVO:
| Element | HV Usage | INVO Adaptation |
|---|---|---|
| "Stop Leaking Money" headline | Hotel pain point | Rephrase for suppliers: "Stop Losing Orders. Start Scaling." |
| Stat cards with progress bars | Hotel savings | Supplier metrics: "2,400+ Hotels Connected", "EGP 180M GMV" |
| "Start Free — No Credit Card" | Hotel CTA | "Connect Free — No Setup Fee" for suppliers |
| "Watch Demo" | Hotel demo | "View API Docs" for developers |
| ETA Compliant card | Hotel compliance | Same — compliance is shared value |
| Trust bar | Hotel types | "TRUSTED BY SUPPLIERS ACROSS EGYPT" |

### What to Change:
1. **Logo:** Hotels Vendors → INVO (with "INFRASTRUCTURE" badge)
2. **Headline:** Keep structure but INVO-focused
3. **Nav:** Features → API | How It Works → Integrations | Pricing → same | Contact → same
4. **CTAs:** Hotel-focused → Supplier/Developer-focused
5. **Subhead:** Hotel procurement → "Connect your inventory to Egypt's largest hotel network"

### Verdict:
**KEEP the layout, card structure, progress bar component, and color scheme.** This is a clean, conversion-focused design. Adapt copy for INVO's infrastructure/supplier audience.
